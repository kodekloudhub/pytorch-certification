# Lab: Using Tensors

Questions 1-8 retain the original tensor fundamentals. Question 9 now introduces
CUDA and MPS backend discovery. Questions 10-14 add PTCA practice for
broadcasting, reshaping, concatenation, stacking, dtype conversion, and memory
layout. Questions 15-16 cover portable CUDA/MPS/CPU selection, indexed CUDA
devices, tensor movement, device and dtype compatibility, and returning results
to CPU.

The setup script downloads Questions 1-16, the shared course requirements, and
the PyTorch logo required by Question 8.

git clone https://github.com/kodekloudhub/pytorch-certification.git
