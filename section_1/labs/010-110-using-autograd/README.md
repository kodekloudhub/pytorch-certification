# Lab: Using Autograd

Complete the files in order. The exercises build from a leaf tensor with
`requires_grad=True` to computation graphs, `backward()`, gradient inspection,
gradient accumulation, and clearing gradients before an optimizer step.

The setup script downloads Questions 1-6 and the shared course requirements.

## Environment setup

```bash
git clone https://github.com/kodekloudhub/pytorch-certification.git
```

```bash
bash pytorch-certification/section_1/labs/010-110-using-autograd/setup.sh
```
