# Lab: Datasets and DataLoaders

Questions 1-7 retain the original dataset exercises. Questions 8-12 cover
batch sizing, shuffle behavior, worker configuration, pinned memory,
`drop_last`, reproducibility, and troubleshooting.

The setup script downloads Questions 1-12, `labels.csv`, and the cat and dog
images used by the custom dataset exercises.
