# Lab: Transformations and Augmentations

Practice composing image transformations, resizing and cropping, converting
images to tensors, normalizing values, and applying random augmentations. The
setup script downloads Questions 1-8 and the cat and dog images used by the
exercises.

## Environment setup

```bash
git clone https://github.com/kodekloudhub/pytorch-certification.git
```

```bash
bash pytorch-certification/section_2/labs/020-060-transformations-and-augmentations/setup.sh
```
