# Demo: Learning Rate Scheduling

Use `learning-rate-scheduling.ipynb` for the course demo. It compares `StepLR`,
`ExponentialLR`, `CosineAnnealingLR`, and `ReduceLROnPlateau` over the same
number of epochs and displays their learning-rate curves for visual comparison.
The companion Python file is preserved as a standalone reference and can save
the comparison as `scheduler_comparison.png`.
