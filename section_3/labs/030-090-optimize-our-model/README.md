# Lab: Optimize Our Model

Practice matching loss functions to prediction tasks, configuring SGD, Adam,
and AdamW, completing an optimization step, and comparing optimizers from the
same initial model state.

The setup script downloads the deterministic prerequisite data and Questions
1-8.
