# Lab: Transfer Learning

Discover pretrained vision models, load ResNet18 and MobileNetV3, replace their
classification heads, freeze and unfreeze parameters, configure learning-rate
schedulers, and save fine-tuning checkpoints. The setup script downloads all
exercise and annotation files plus the shared breast-cancer image dataset.

## Environment setup

```bash
git clone https://github.com/kodekloudhub/pytorch-certification.git
```

```bash
bash pytorch-certification/section_3/labs/030-120-transfer-learning/setup.sh
```
