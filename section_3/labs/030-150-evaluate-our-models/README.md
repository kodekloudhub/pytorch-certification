# Lab: Evaluate Our Models

Create a deterministic test DataLoader, restore the fine-tuned ResNet18 and
MobileNetV3 models, and evaluate both with TorchMetrics inside
`torch.inference_mode()`. The setup script downloads all exercise files, test
annotations, model checkpoints, and the shared breast-cancer image dataset.

## Environment setup

```bash
git clone https://github.com/kodekloudhub/pytorch-certification.git
```

```bash
bash pytorch-certification/section_3/labs/030-150-evaluate-our-models/setup.sh
```
