# Lab: Train and Save an Image Classifier

Build the breast-cancer classifier, configure its loss and optimizer, train and
validate it, save checkpoints, restore a trained model, and run a sample
prediction. The setup script downloads every exercise and annotation file,
sample input image, and the shared breast-cancer image dataset.

## Environment setup

```bash
git clone https://github.com/kodekloudhub/pytorch-certification.git
```

```bash
bash pytorch-certification/section_3/labs/030-060-train-and-save-an-image-classi/setup.sh
```
